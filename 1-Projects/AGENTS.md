# Projects

Short-term efforts with a defined goal and deadline. You can finish a project.

**Statuses:** `planned` → `active` → `done` (also `on-hold`)

**Structure:** Each project is a Markdown file (or subfolder for large projects) with tasks, notes, and related links.

**Ongoing projects:** Some projects have status `ongoing` — these represent recurring maintenance work within an Area (e.g. "Health — Ongoing" for recurring health tasks). This bridges tasks to areas without a direct relation.

**Agent rules:** Read for context on what the human is working on. Don't create projects without being asked. When researching, link your wiki articles to relevant projects using frontmatter `related:` fields.

**Templates:** `_admin/templates/para/Project.md`
