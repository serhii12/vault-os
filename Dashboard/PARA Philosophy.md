# PARA

## The System

Projects, Areas, Resources, Archive — four folders sorted by actionability.

| Category | What | End? | Example |
|---|---|---|---|
| Projects | Defined goal + deadline | Yes | Launch website |
| Areas | Standard to maintain | No | Health, Finances |
| Resources | Topical interest | No | Gardening, AI |
| Archive | Inactive from above | — | Cold storage |

## Three Habits

**Organize for action.** File by what you're working on, not by subject.

**Keep information flowing.** Nothing stays in one place forever. Move things as their actionability changes.

**Protect your ideas.** Capture first, judge later. New ideas need space.

## Distinguishing

Projects have end goals. Areas don't. If you can complete it, it's a project.

Areas carry responsibility. Resources don't. If neglecting it causes problems, it's an area.

Resources can become areas. Areas can spawn projects. Projects complete into archives.

## Setup

1. Archive everything into a dated folder
2. Create project folders only for active work
3. Everything else emerges from use

Never create empty folders. Let structure grow from actual use.

## Maintenance

Five minutes per week: rename inbox items, file them, update project statuses.

The system fails gracefully — search finds things even if you file them wrong.

When overwhelmed, archive everything and start fresh. Nothing is deleted.

## Focus

Four types of work:

|  | Attractive | Unattractive |
|---|---|---|
| Productive | **Purposeful** | Necessary |
| Unproductive | Distracting | Unnecessary |

Spend focus sessions on purposeful work. Three priorities per day, not ten.

Your brain holds four things in working memory. Focus on one task at a time. Capture stray thoughts, don't act on them. Average focus on a computer: 40 seconds before distraction.

Four stages: Choose → Eliminate → Focus → Refocus.

Scatterfocus (walks, showers) is where creative connections happen. You need both modes.

## Habits

Cue → Routine → Reward. You can't destroy habits — keep the cue and reward, replace the routine.

Keystone habits cascade: daily planning makes everything else more intentional.

Craving drives habits. The reward of crossing off your three priorities creates craving for the planning ritual.

Habit change breaks under stress without belief and community. Share your system.
