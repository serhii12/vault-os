# PARA Overview

> PARA is a universal system for organizing digital information by actionability.

## The Four Categories

**Projects** -- Short-term efforts with a defined goal and deadline. You can finish a project. Examples: launch a website, plan a trip, write an article.

**Areas** -- Long-term responsibilities with standards to maintain. These never "finish." Examples: health, finances, career, home. If you neglect an area, things fall apart.

**Resources** -- Topics of interest with no personal responsibility attached. Examples: gardening, cooking, AI research. No consequences if you ignore them for a month.

**Archive** -- Inactive items from the other three categories. Not deleted, stored in cold storage for future retrieval.

## Key Principles

1. **Organize for action, not by topic.** Group information by what you're working on right now.
2. **The right place depends on right now.** Information flows between categories as your life changes.
3. **Organize as little as possible, as late as possible.** Don't pre-create empty folders. Let the system grow organically from actual use.
4. **Archive is not a graveyard.** It's a treasure chest of reusable ideas.

## The Actionability Spectrum

```
INBOX -> PROJECTS -> AREAS -> RESOURCES -> ARCHIVE
(most actionable)                    (least actionable)
```

## The 60-Second Setup

1. Archive all existing files into a dated archive folder
2. Create project folders only for things you're actively working on
3. That's it. Areas and Resources emerge as needed.
