# PARA Maintenance

> Maintaining PARA should take five minutes per week.

## The Three Core Habits

### 1. Organize for Action
File things by the project they serve, not by subject or topic. When you save a research paper, ask "which active project does this help?" not "what category does this belong to?"

### 2. Keep Information Flowing
Nothing lives in one place permanently. As your relationship to information changes, move it:
- Resource note becomes relevant to a project -- link or move it
- Project completes -- archive the folder
- Area shrinks in importance -- demote to Resource
- Resource grows in responsibility -- promote to Area

### 3. Protect Your Ideas
New ideas are fragile. Capture first, judge later. PARA folders are protected spaces for fledgling ideas to develop. Don't critique during capture. That's for weekly review.

## 5-Minute Weekly Maintenance

1. **Rename** -- Give meaningful titles to items sitting in your Inbox
2. **File** -- Move each Inbox item to the correct PARA folder
3. **Update** -- Check project statuses: any done? any stalled? any newly active?

## Information Bankruptcy

When your system feels overwhelming: archive everything, start fresh. Move all Projects, Areas, and Resources into a dated Archive folder. Only pull things out when you actively need them. This eliminates organizational debt.

## The Desire Paths Principle

Never create an empty folder before you have something to put in it. Like a landscape architect who waits for foot traffic to wear paths in the grass before laying sidewalks. Let your organizational structure emerge from actual use patterns.
