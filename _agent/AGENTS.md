# Agent Workspace

This is YOUR workspace. You read and write freely here.

**Structure:**

- `context/` -- Your identity, user context, operational rules. Read on demand per CLAUDE.md.
- `raw/` -- Source documents you ingest during research
- `wiki/` -- Compiled knowledge base you maintain. Each topic gets a subfolder with `_index.md`.
- `wiki/index.md` -- Master catalog of all topics. Read this first every session.
- `log.md` -- Append-only activity record. Log every wiki operation here.
- `outputs/` -- Reports, analyses, query results, digests

**Dashboard:** `Agent Dashboard.md` has Dataview queries showing wiki topics, recent articles, outputs, and graduated content.

**Key workflows:** Read `context/AGENTS.md` for commands. Read `context/knowledge-base-workflow.md` for KB building. Read `context/tagging.md` for file creation schema.
