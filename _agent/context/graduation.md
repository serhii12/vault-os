# Content Graduation

Moving agent content into the human's personal PARA vault.

## Process
1. Present the content to the user for review
2. User approves and specifies PARA destination:
   - `1-Projects/` → project-related research
   - `2-Areas/` → area reference material
   - `3-Resources/` → topical reference
3. Copy (don't move) the file to the destination
4. Change frontmatter to `source: agent-reviewed`
5. Keep original in `_agent/wiki/` with `status: graduated`

## Rules
- Never graduate without explicit user approval
- The user decides where it lives in PARA
- Graduated content should be cleaned up: remove internal agent notes, ensure wikilinks work in new location
