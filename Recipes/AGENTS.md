# Recipes

Recipe collection and meal planner.

**Properties:** cuisine, course, prep-time, cook-time, total-time, servings, source URL, favorite, is-quick (≤45 min).

**Meal planning:** Separate meal plan notes link to multiple recipes and go on a calendar.

**Recipe inbox:** New captures go to inbox first (inbox: true) until cleaned up.

**Agent rules:** If asked to find or research recipes, save findings to `_agent/wiki/` first. Only create recipe entries here when explicitly asked.

**Templates:** `_admin/templates/para/Recipe.md`
