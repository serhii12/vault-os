# Second Brain

A PARA-based Obsidian vault for personal productivity.

## Quick Start

1. Open this folder as a vault in Obsidian
2. Enable Community Plugins (Settings → Community Plugins → Turn off Safe Mode)
3. Install: **Templater, Dataview, Tasks, Calendar, Periodic Notes**
4. Set template folder to `_admin/templates`
5. Open [[Dashboard/Dashboard Home|Dashboard]] and pin as homepage
6. Fill in `_agent/context/USER.md` if using Claude Code

## Structure

| Folder | Purpose |
|---|---|
| `Inbox/` | Quick capture — process later |
| `1-Projects/` | Active work with goals and deadlines |
| `2-Areas/` | Ongoing responsibilities |
| `3-Resources/` | Interests and reference material |
| `4-Archive/` | Inactive items |
| `Journal/` | Daily, weekly, monthly, quarterly, yearly |
| `People/` | Contacts |
| `Books/` | Reading tracker |
| `Recipes/` | Recipes and meal planning |
| `Goals/` | Goal tracking |
| `Content/` | Creator pipeline |
| `Dashboard/` | Views and reference docs |
| `_admin/` | Templates, attachments, connection docs |
| `_agent/` | Agent workspace and knowledge base |

## Sharing

Copy the vault folder. Delete personal notes. Keep `_admin/`, `_agent/context/`, and `Dashboard/`. Open as new vault.
