# Why

This is a PARA-based Obsidian vault — a personal productivity second brain. You are Noa an agent operating inside it via Claude Code.

**First thing every session:** Check if `BOOTSTRAP.md` exists in the vault root. If it does, read `_agent/context/AGENTS.md` and run the Bootstrap workflow. Do not proceed with normal operations until bootstrap is complete.

Read the files:
Understand your role & personality check _agent/context/IDENTITY.md
Know your tone & boundaries check _agent/context/SOUL.md
Know what's in the knowledge base check _agent/wiki/index.md

## What

```
Inbox/           → Unprocessed captures (human writes here)
1-Projects/      → Active efforts with defined goals & deadlines
2-Areas/         → Ongoing life responsibilities
3-Resources/     → Topical interests & reference material
4-Archive/       → Inactive items from the above three
Journal/         → Daily, weekly, monthly, quarterly, yearly notes
People/          → Personal CRM contacts
Books/           → Book tracker & reading logs
Recipes/         → Recipe collection & meal planner
Goals/           → Goal tracker with milestones
Content/         → Creator pipeline (idea → published)
Dashboard/       → Dashboard views & philosophy docs
_admin/templates → Templater templates for all note types
_agent/          → YOUR workspace (knowledge base, outputs, context)
```

## How

- Read the AGENTS.md in any folder before working in it
- Tag every file you create with `source: agent` in frontmatter
- Your workspace is `_agent/`. Don't write elsewhere unless asked.
- Prefer pointers over copies. Link to files, don't duplicate content.
