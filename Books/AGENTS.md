# Books

Book tracker with reading logs and ratings.

**Statuses:** `to-read` → `reading` → `read` (also `on-hold`)
**Properties:** author, genre, rating (1-7 scale), format, date-started, date-finished, favorite, read-next.

**Reading log:** Track daily pages read inside each book's page.

**Agent rules:** Read for context on what the human reads. If asked to research a book, create a wiki article in `_agent/wiki/` — don't create entries here directly.

**Templates:** `_admin/templates/para/Book.md`
