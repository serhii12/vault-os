# Content

Creator's pipeline for content production.

**Pipeline:** `idea` → `planned` → `drafting` → `editing` → `ready` → `published`
**Properties:** content-type, platform, publish-date, status.

**Integration:** Content research uses the notes system. Tasks for content production can link to projects.

**Agent rules:** If asked to help with content, research goes to `_agent/wiki/`. Draft content goes to `_agent/outputs/`. Only create entries here when explicitly asked.

**Templates:** `_admin/templates/content/Content Idea.md`
