# Journal

Private periodic notes. Daily, weekly, monthly, quarterly, yearly.

**Structure:**
- `daily/` — One note per day (Templater template)
- `weekly/` — Weekly reviews and planning
- `monthly/` — Monthly goals and reflection
- `quarterly/` — Quarterly objectives
- `yearly/` — Annual review

**Agent rules:** This is the human's private journal. Don't read unless explicitly asked (e.g. "analyze my week" or "summarize my daily notes"). Never write here. When generating a daily brief, check if today's daily note exists and reference it.

**Templates:** `_admin/templates/periodic/`
