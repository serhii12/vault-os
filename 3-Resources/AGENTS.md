# Resources

Topical interests with no personal responsibility. No consequences if ignored.

**Examples:** Gardening, cooking, AI research, a programming language.

**Structure:** Each resource has an index page with Dataview queries for related notes and web clips. Resources can contain subfolders for deep topics.

**Entity type:** Some tags describe the shape of information (papers, apps, essays) rather than the topic. These coexist with resources.

**Graduation target:** When you research a topic and the human approves, agent wiki content often lands here. Read `_agent/context/graduation.md` for the process.

**Agent rules:** This is the most common destination for graduated agent content. Don't create resources without being asked.

**Templates:** `_admin/templates/para/Resource.md`
